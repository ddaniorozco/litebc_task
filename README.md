# Capillary Detection

This project aims to detect capillaries in microscopy images using the YOLO (You Only Look Once) object detection algorithm. The detection system is designed to identify capillaries in images and provide bounding box coordinates for further analysis.

## Introduction

Capillary detection plays a crucial role in various medical applications, particularly in blood flow analysis and disease diagnosis. This project leverages the YOLO algorithm to detect capillaries in microscopy images, facilitating blood flow recording and analysis.
